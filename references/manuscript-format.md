# Manuscript format specification

This file records formatting distilled from the source manuscript only. It intentionally excludes research content and argumentation.

## Page setup

- Paper: A4 portrait, 21.0 x 29.7 cm.
- Top margin: 2.299 cm (OOXML 1304 twips; approximately 2.30 cm).
- Bottom margin: 1.700 cm (964 twips; approximately 1.70 cm).
- Left margin: 2.501 cm (1418 twips; approximately 2.50 cm).
- Right margin: 1.501 cm (851 twips; approximately 1.50 cm).
- Header distance: approximately 1.50 cm.
- Footer distance: approximately 1.75 cm.
- Columns: one.
- Line numbers: every line, continuous through the document.
- No required visible header or footer content.

## Font mapping

- Latin body text: Times New Roman.
- Chinese body text: SimSun / 宋体.
- Chinese headings and title: SimHei / 黑体.
- Word equations: Cambria Math.

## Article-type label

If present above the title, preserve its text and use the manuscript body font at 10.5 pt. Do not invent one.

## Paper title

- 18 pt.
- Bold.
- Latin: Times New Roman.
- Chinese: SimHei / 黑体.
- Left aligned visually.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.

## Authors, affiliations, corresponding author

- 11 pt.
- Latin: Times New Roman.
- Chinese: SimSun / 宋体 unless the source already uses a deliberate alternative.
- Left aligned.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.
- Line spacing: 1.5.
- Preserve superscripts, affiliation markers, asterisks, emails, and symbols.

## Abstract

- Prefix `Abstract:` or `摘要：` bold.
- Abstract text regular.
- 10.5 pt.
- Latin: Times New Roman.
- Chinese: SimSun / 宋体.
- Justified.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.
- Line spacing: 1.7.
- Space before/after: 0 unless the source contains an intentional separator paragraph.

## Keywords

- Prefix `Keywords:` or `关键词：` bold.
- Keyword text regular.
- 10.5 pt.
- Same font mapping and indentation as Abstract.
- Line spacing: 1.7.

## Numbered headings

Applies to levels such as `1`, `2.1`, and `2.1.1`.

- 12 pt.
- Bold.
- Latin: Times New Roman.
- Chinese: SimHei / 黑体.
- Left aligned.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.
- Line spacing: 2.0.
- Space before: 15.6 pt.
- Space after: 15.6 pt.

The source template uses the same visual size for the main numbered heading levels. Keep hierarchy through numbering, not through invented size changes.

## Body paragraphs

- 10.5 pt.
- Latin: Times New Roman.
- Chinese: SimSun / 宋体.
- Justified.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.741 cm.
- Line spacing: 2.0.
- Space before: 0.
- Space after: 0.

## Figure paragraphs

- Center paragraphs containing a figure/image.
- Do not change image content, crop, scale, or aspect ratio unless explicitly asked.

## Figure captions

Pattern examples only:

- English: `Fig. 1. [caption]`
- Chinese: `图 1. [题注]`

Format:

- caption below the figure
- 10.5 pt
- Latin: Times New Roman
- Chinese: SimSun / 宋体
- bold label prefix only
- caption text regular
- no first-line indent
- short one-line caption: centered
- long multi-line caption: may use justified alignment across manuscript text width
- line spacing: 2.0

## Table captions

Pattern examples only:

- English: `Table 1 [caption]`
- Chinese: `表 1 [题注]`

Format:

- caption above the table
- centered
- 10.5 pt
- bold label prefix only
- caption text regular
- no first-line indent
- line spacing: 2.0

## Ordinary data tables

Use a three-line scientific-table treatment derived from the source tables:

- table centered
- top border: single, 0.5 pt
- bottom border: single, 0.5 pt
- left border: none
- right border: none
- inside vertical border: none
- inside horizontal border: none by default
- header-row top border: single, 1.0 pt
- header-row bottom border: single, 1.0 pt
- 10.5 pt cell text
- Latin: Times New Roman
- Chinese: SimSun / 宋体
- vertically center cells
- center short headers and numerical cells
- preserve deliberate line breaks in multi-line headers

Do not blindly apply this rule to special-purpose layout tables, equation tables, or abbreviation tables.

## Numbered equations

The source manuscript uses borderless layout tables for numbered equations.

Target appearance:

- Word equation in the center zone
- equation number at the far right, e.g. `(1)`
- no visible borders
- equation number regular text
- equation object uses Cambria Math through Word's native equation system

Preserve existing equation objects and numbering. Do not rewrite formulas as plain text.

## References

- Section heading: same numbered-heading visual family, 12 pt bold.
- Reference entries: 10.5 pt.
- Latin: Times New Roman.
- Chinese: SimSun / 宋体 where applicable.
- Justified or source-consistent alignment.
- Left indent: 0.741 cm.
- Right indent: 0.741 cm.
- First-line indent: 0.
- Line spacing: 2.0.
- Preserve citation text, DOI, punctuation, ordering, italics, and hyperlinks.

## Content preservation

Formatting must not modify:

- scientific terminology
- numerical values
- units
- citations
- formulas
- figure/table numbering
- author names
- affiliations
- claims or conclusions
